Sales Voucher Import for Tally Prime

Converts CSV sales data into Tally Prime XML for item voucher import.

Usage:
  npx github:durga6630/tally-import input.csv -o output.xml

Supports:
  - Multiple items per invoice
  - Tax ledgers (GST, TCS, etc.)
  - Batch/godown allocation
  - Custom voucher numbering
  - Auto-company selection
